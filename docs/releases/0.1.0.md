# widgetctl 0.1.0

First public release of the CLI, TypeScript library, optional Playwright fixture and agent skill/plugins.

- 📱 Pick a simulator, app, widget and size interactively.
- 🧩 Add, find and remove individual Home Screen widgets using exact identities.
- ✏️ Edit supported AppIntent configuration with typed fields, native choices and guarded saves.
- 🤖 Use `--json` for prompt-free automation, or keep one prepared session through the TypeScript API and Playwright fixture.
- 🩺 Diagnose the local environment with `widgetctl doctor`.

```sh
npm install --global widgetctl
widgetctl
```

For a project, use `npm install --save-dev widgetctl`. For Playwright, install `widgetctl @playwright/test` and import from `widgetctl/playwright`. See the [README](https://github.com/DimaMishchenko/widgetctl/blob/v0.1.0/README.md) and [agent setup](https://github.com/DimaMishchenko/widgetctl/blob/v0.1.0/docs/agents.md) for plugin and skill installation.

Requires macOS, Node 22.14+, full Xcode and an installed widget app. Live development coverage includes arm64 iPhone simulators on iOS 26.0, 27.0 and Duo 27.1. Physical devices, stacks and Lock Screen widgets are unsupported; iPad and Intel remain unverified. The release acceptance report records the exact packaged-artifact environment. Private Apple APIs may change with Xcode or simulator updates.

Reserve one simulator per worker. Preparation/release can restart its Home Screen. Release in `finally`, including setup failures; preserve unrelated widgets. A failed write may already have completed, so inspect saved state before retrying.

The plugin ZIP supplies instructions, not the executable. Repository marketplaces are the initial plugin channel. The public OpenAI directory requires separate publisher verification and review.

Before 1.0, patch releases preserve the public API/CLI; breaking changes use a minor version. Roll back a bad rollout through a fixed patch or npm deprecation/tag correction rather than rewriting published Git tags. This first release uses authenticated npm publishing; it does not claim GitHub Actions provenance.
