# widgetctl 0.2.0

Connect agents to iOS Simulator widgets through a local MCP server. The plugin now bundles the skill, CLI and MCP executable with runtime dependencies and the native worker. Standalone skills retain the bundled CLI and can optionally register the included MCP server.

```sh
npm install --global widgetctl
widgetctl-mcp --version
```

Configure an MCP client's local stdio server with command `widgetctl-mcp`. It can discover devices, installed apps, widget kinds and sizes; add widgets; describe settings; query entity choices; export and apply guarded configurations; and remove exact widget instances. Every simulator request requires an explicit UDID. Configuration writes require the unchanged original as `expected`. Requests serialize, release their helper on failures and wait for active cleanup on shutdown.

The CLI, TypeScript and Playwright APIs remain available. Plugins include OpenAI and Claude MCP configurations; the Anthropic adapter also includes a listing icon. [Agent installation](https://github.com/DimaMishchenko/widgetctl/blob/v0.2.0/docs/agents.md), [MCP tools](https://github.com/DimaMishchenko/widgetctl/blob/v0.2.0/docs/mcp.md) and [directory submission steps](https://github.com/DimaMishchenko/widgetctl/blob/v0.2.0/docs/distribution.md#directory-submissions) explain the separate channels. No public provider approval is claimed. OpenAI local MCP submissions require organization allowlisting.

Requires macOS, Node 22.14+ and full Xcode. Physical devices, stacks and Lock Screen widgets are unsupported. Native acceptance evidence attached to the release records the tested simulator and rendered results. Apple private API compatibility can change after OS or Xcode updates.
