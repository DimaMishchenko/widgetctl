# widgetctl 0.2.1

The README now leads with installation, agent setup and concise CLI/API/Playwright examples. Support limits live in the README; contributor verification and release instructions have one home. Redundant compatibility, performance and release-checklist pages and unpublished candidate notes were removed.

The interactive CLI loads only its five used Inquirer prompts. This removes six unused packages and their bundled license folders without upgrading dependencies or changing prompts. The CLI bundle is 9 KB smaller. CLI, MCP, library and Playwright behavior remain unchanged.

```sh
npm install --global widgetctl
widgetctl
```

Plugins continue to bundle the skill, CLI and local MCP server. The skill is now discoverable in [Tessl](https://tessl.io/registry/skills/github/DimaMishchenko/widgetctl/widgetctl); its GitHub installer preserves the complete bundled runtime. See [agent setup](https://github.com/DimaMishchenko/widgetctl/blob/v0.2.1/docs/agents.md).

Requires macOS, Node 22.14+ and full Xcode. OpenAI directory approval remains separate from GitHub marketplace installation. Anthropic directory submission is optional; its compatible repository adapter remains available.
