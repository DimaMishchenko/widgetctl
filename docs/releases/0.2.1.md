# widgetctl 0.2.1

The README now leads with installation, agent setup and concise CLI/API/Playwright examples. Support limits live in the README; contributor verification and release instructions have one home. Redundant compatibility, performance and release-checklist pages and unpublished candidate notes were removed.

The interactive CLI loads only its five used Inquirer prompts. This removes six unused packages and their bundled license folders while preserving the prompts. The prompt import cleanup reduces the CLI bundle by 9 KB.

```sh
npm install --global widgetctl
widgetctl
```

Plugins continue to bundle the skill, CLI and local MCP server. The skill is now discoverable in [Tessl](https://tessl.io/registry/skills/github/DimaMishchenko/widgetctl/widgetctl); its GitHub installer preserves the complete bundled runtime. See [agent setup](https://github.com/DimaMishchenko/widgetctl/blob/v0.2.1/docs/agents.md).

Requires macOS, Node 22.14+ and full Xcode. OpenAI directory approval remains separate from GitHub marketplace installation. Anthropic directory submission is optional; its compatible repository adapter remains available.

Dependency updates include plist 5, bplist-parser 0.5, TypeScript 7, current Node types, Playwright and formatting tools, plus the current GitHub Actions majors. Binary metadata retains exact integers, UID identity and data values. Older Playwright 1.50 consumers remain checked with the documented TypeScript 5.9 toolchain.

New `waitForWidgetDescriptor` and local MCP `widgetctl_wait_for_descriptor` provide a bounded, cancellable read-only wait for first-launch registration. They reuse an already prepared helper, fail on errors or ambiguity, and leave placement explicit. Add/reveal results now state that Home Screen visibility is unverified; native UI checks establish the visible outcome.

CLI and MCP diagnostic output preserves exact binary metadata integers with `{"$bigint":"decimal"}` tags, so successful removals remain serializable. Canonical widget configuration still uses ordinary finite JSON values.
