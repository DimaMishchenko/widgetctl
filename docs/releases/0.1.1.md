# widgetctl 0.1.1

Adds a manual GitHub Actions release workflow with npm trusted publishing and provenance. The workflow tests supported host environments, builds the npm and plugin packages, checks native acceptance against the exact tarball, and publishes matching GitHub assets. No stored npm write token is needed.

The plugin now includes a ready-to-run CLI, native worker and production dependencies with license notices. Agents can use it immediately without a separate npm installation. Node 22.14+ and Xcode remain prerequisites; global PATH and project dependencies are unchanged. It also links support, local-data privacy information and the existing MIT license. The CLI and widget runtime behavior are unchanged. The public OpenAI directory currently blocks new skills-only submissions; repository plugin and standalone skill installation remain available.

```sh
npm install --global widgetctl
widgetctl
```

For projects use `npm install --save-dev widgetctl`; for Playwright install `widgetctl @playwright/test` and import `widgetctl/playwright`. See the [README](https://github.com/DimaMishchenko/widgetctl/blob/v0.1.1/README.md), [agent setup](https://github.com/DimaMishchenko/widgetctl/blob/v0.1.1/docs/agents.md) and [release process](https://github.com/DimaMishchenko/widgetctl/blob/v0.1.1/docs/distribution.md).

Requires macOS, Node 22.14+ and full Xcode. Live development coverage includes arm64 iPhone simulators on iOS 26.0, 27.0 and Duo 27.1; the attached acceptance report records this artifact’s test environment. Physical devices, stacks and Lock Screen widgets are unsupported. Reserve a simulator per worker and release in `finally`; Apple private API compatibility can change after OS or Xcode updates. Patch releases preserve the public API before 1.0; breaking changes use a minor version.
